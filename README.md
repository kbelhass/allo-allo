# Allo-Allo

Application de rencontre (React + Express + PostgreSQL).

- **Déploiement Oracle Cloud** : voir [`DEPLOIEMENT_ORACLE.md`](DEPLOIEMENT_ORACLE.md)
- **Corrections et points restants** : voir [`CORRECTIONS.md`](CORRECTIONS.md)

## Développement local
```bash
npm install
npm run dev        # http://localhost:3000 (données dans des fichiers JSON locaux)
```
Pour tester l'accès admin en local : `ADMIN_EMAIL=moi@test.tn ADMIN_PASSWORD=monmotdepasse npm run dev`
